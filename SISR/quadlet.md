.container (Non validé)
Définit un conteneur	           
``` bash
podman run
```
.volume (Non validé)
Crée un volume persistant
``` bash
podman volume create
```

.network (Non validé)    
Configure un réseau interne
``` bash
podman network create
```
.pod (Non validé)
Regroupe plusieurs conteneur
(Podman 5+)	
``` bash
podman pod create
```
.image (Non validé)
Gère le téléchargement d'image
``` bash
podman pull
```
